Qué hace un router

  • Puerta de enlace: es la salida de la red local hacia internet.
  • NAT: traduce las IP privadas de casa a una única IP pública.
  • DHCP: asigna direcciones IP automáticamente a cada dispositivo.
  • Wifi: los routers domésticos suelen llevar punto de acceso integrado.

What a router does

  • Gateway: it is the exit from the local network to the internet.
  • NAT: translates the private IP addresses at home into a single public IP address.
  • DHCP: automatically assigns IP addresses to each device.
  • Wi-Fi: home routers usually include a built-in access point.

Tipos y seguridad

  • Doméstico: todo en uno, para uso en casa.
  • Empresarial: más puertos, VPN y varias conexiones a internet.
  • Mesh: varios nodos wifi que cubren una casa grande.

Conviene cambiar la contraseña de administración de fábrica, usar cifrado WPA2 o WPA3 y mantener el firmware actualizado.

Types and security

  • Home: all-in-one, for use at home.
  • Business: more ports, VPN and several internet connections.
  • Mesh: several Wi-Fi nodes that cover a large home.

It is advisable to change the factory administration password, use WPA2 or WPA3 encryption and keep the firmware up to date.
